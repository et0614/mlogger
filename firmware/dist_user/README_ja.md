# M-Logger ファームウェアの更新

M-Logger 本体のファームウェアを、USB で PC から書き換えます (v4 以降)。

| ファイル | 内容 |
|---|---|
| `update.bat` | 更新を始めるファイル (Windows) |
| `avrdude.exe`, `avrdude.conf` | 書き込みツール (avrdude 8.1、GPL v2。ライセンスは `COPYING_avrdude.txt`) |
| `mlogger_main.X.production.hex` | 新しいファームウェア |

*English version: [README.md](README.md)*

## 手順 (Windows)

1. **電池を取り外します。** 電源スイッチは USB 給電と電池給電の切り替えなので、電池を入れたままでは電源が切れません。
2. 電源スイッチを**電池給電の側**にしたまま、USB ケーブルで M-Logger を PC につなぎます。電池がないので、電源は入りません。
3. `update.bat` をダブルクリックします。
4. 画面の説明を読み、**Reset ボタンを押したまま、電源スイッチを USB 給電の側に切り替えます**。
5. 赤 LED が点滅していることを確かめてから、Reset ボタンを離します。これで書き込み待ちの状態です。
6. `update.bat` の画面で Enter キーを押すと、書き込みが始まります (10 秒ほど)。
7. 「書き込み完了」と表示されたら、電源スイッチを一度電池給電の側に戻してから USB 給電の側にします。新しいファームウェアで起動します。

## 注意

- 書き込み中は USB ケーブルを抜いたり、スイッチを切り替えたりしないでください。
- PC には M-Logger を 1 台だけつないでください。
- 書き込みに失敗した場合は、電源スイッチを電池給電の側に戻し、手順 3 からやり直してください。

macOS / Linux での手順は、ユーザーマニュアルの「ファームウェアの更新」を参照してください。
