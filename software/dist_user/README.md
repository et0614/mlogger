# M-Logger Tools

This package contains:

- **`python_tools/`** — use an M-Logger from a PC over USB: check the device,
  download recorded data, clear recorded data.
  See [python_tools/README.md](python_tools/README.md).

- **`MLServer/`** — receive and log measurement data from M-Loggers over
  Zigbee. See [MLServer/README.md](MLServer/README.md).

- **`firmware_update/`** — update the firmware of the M-Logger device over USB.
  See [firmware_update/README.md](firmware_update/README.md).
