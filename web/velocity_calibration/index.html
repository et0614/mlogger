M-Logger Anemometer Calibration Report

Enter the air-velocity probe ID (6 hexadecimal digits). The ID is printed on the probe label, listed in the factory inspection report of the main unit, and shown as "Velocity probe ID" in the device settings screen of the smartphone app.

6 characters, 0-9 / A-F only. Web reports are available for M-Logger version 4 or later.
