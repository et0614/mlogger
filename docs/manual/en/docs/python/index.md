# Python tools

<span class="fw">v4+</span> These tools talk to the M-Logger over USB, so they work only with M-Loggers running v4 firmware.

Command-line tools for an M-Logger connected to a PC by USB.

| Script | Purpose |
|---|---|
| [`check_device.py`](check_device.md) | Device check: connection, battery, probes, current sensor readings |
| [`load_data.py`](load_data.md) | Download recorded data and save it as a CSV file |
| [`clear_data.py`](clear_data.md) | Clear the data recorded on the M-Logger |

Complete the [Setup](install.md) before use.
