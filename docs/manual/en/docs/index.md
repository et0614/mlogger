# M-Logger User Manual

This manual explains how to use the indoor thermal-environment measurement system **M-Logger**: basic operation of the device, and the software that operates it (smartphone app, MLServer, Python tools).

## Contents

| Chapter | Topics |
|---|---|
| [Getting started](start/system.md) | System overview, basic device operation, firmware versions, supported features and updates |
| [Smartphone app](mobile/index.md) | Set up and measure with one M-Logger from a smartphone |
| [PC (MLServer)](server/index.md) | Collect readings from multiple units on a PC over Zigbee |
| [Python tools](python/index.md) | Download or clear recorded data and check operation over USB |
| [Appendix](appendix/troubleshooting.md) | Troubleshooting, glossary |

## Differences between firmware versions

Some features and screens differ depending on the firmware version of the M-Logger. For how to tell the versions apart and how this manual marks the differences, see [Firmware versions and supported features](start/firmware.md).
