# ファームウェアの版と対応機能

## 版の確認方法

- **スマートフォンアプリ**: 接続すると自動で判別され、画面が切り替わります。[計測の設定](../mobile/settings.md) 画面の下部「その他の設定」に表示される **M-Logger バージョン** が `4.x.x` なら v4、`3.x.x` なら v3 です。
- **Python ツール** <span class="fw">v4 以降</span>: [`check_device.py`](../python/check_device.md) の「Firmware」の欄に表示されます。
- **MLServer**: M-Logger から最初に受信したときに、画面に `<名前>: Protocol = v4 (JSON-RPC), FW 4.0.0` のように表示されます (v3 は `Protocol = v3`)。計測中の M-Logger は応答できないため、表示されないことがあります。

## このマニュアルでの表し方

- 一部の版でだけ使える機能には、<span class="fw">v4 以降</span> のような印を付けています。
- 操作や画面が版によって異なる箇所は、「v4 ファームウェア」「v3 ファームウェア」のタブで切り替えて表示します。

## 機能と対応ファームウェア

各所に付けた版の印は、この表に基づいています。

| 機能 | v4 | v3 |
|---|:---:|:---:|
| スマートフォンからの設定・計測 | ○ | ○ |
| 電池電圧の表示 | ○ | − |
| スマートフォンでの記録データのダウンロード・消去 | ○ | − |
| Zigbee による PC への送信 (MLServer) | ○ | ○ |
| USB 通信 (Python ツール) | ○ | − |
| 本体への記録 | ○ (内蔵メモリ) | ○ (メモリカード) |
| USB でのファームウェアの更新 | ○ | − |

## 主な違い

| ファームウェア | 主な違い |
|--------------|---------|
| **v4** | センサ設定が 3 カテゴリに集約 / 電池情報を表示 / スマホから記録データのダウンロード・消去が可能 |
| **v3** | センサ設定はセンサ別 5 行 / 電池・記録データ管理は表示なし / 記録データはメモリカードを取り出して PC のカードリーダで読み出す |
