# システムの構成

M-Logger は、室内の温熱環境を計測する小型の計測器です。本体にプローブを挿して使い、計測値はスマートフォンや PC で受け取ります。

![組み立てた状態](../assets/photos/device_assembled.jpg){ width="400" }

## 本体とプローブ

| 部品 | 計測するもの |
|---|---|
| 本体 | 照度。無線 (Zigbee / Bluetooth)、USB、内蔵メモリを備える |
| 温湿度・CO2 プローブ (グローブ球付き) | 乾球温度、相対湿度、CO2 濃度、グローブ温度 |
| 風速プローブ | 風速 (微風速) |

プローブは本体上面の 2 か所の差し込み口のどちらにも挿せます。風速を計測しないときは、風速プローブを外して電池ボックスの蓋の裏に収納できます ([本体の基本操作](device.md))。

計測値からは、平均放射温度 (MRT)、PMV、PPD、SET\*、WBGT などの指標も計算できます。

## 計測値の受け取り方

| 使い方 | 通信 | ソフトウェア |
|---|---|---|
| 1 台を手元で設定・計測する | Bluetooth (BLE) | [スマートフォンアプリ](../mobile/index.md) |
| 本体の内蔵メモリに記録し、後で取り出す | Bluetooth または USB <span class="fw">v4 以降</span> | [スマートフォンアプリ](../mobile/data.md) または [Python ツール](../python/load_data.md) |
| 複数台の計測値を PC に集める | Zigbee | [MLServer](../server/index.md) |
| USB で動作確認や記録データの取り出しをする | USB <span class="fw">v4 以降</span> | [Python ツール](../python/index.md) |

計測の設定 (計測する項目、間隔、記録先) は、どの使い方でもスマートフォンアプリで行います。
