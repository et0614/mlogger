# 用語

**常設モード**
: 電源を入れると自動で計測を始め、計測値を PC (Zigbee) に送る設定。電池の交換などで電源が切れても、入れ直せば計測を再開する。本体の Reset ボタンを 3 秒以上押すと解除できる ([本体の基本操作](../start/device.md))。

**記録先**
: 計測値を送る先・保存する先。スマートフォン (Bluetooth)、PC (Zigbee)、本体の内蔵メモリがある。スマートフォンアプリの [計測の設定](../mobile/settings.md) で選ぶ。

**親機 / 子機**
: Zigbee で計測値を集めるときの呼び方。PC に挿した XBee が親機 (Coordinator)、各 M-Logger が子機。

**XBee**
: M-Logger と親機に使っている無線モジュール。Zigbee と Bluetooth (BLE) の通信を担う。

**PAN ID**
: Zigbee のネットワークの番号。PAN ID が同じ機器どうしだけが通信する ([Zigbee 親機の準備](../server/coordinator.md))。

**ハードウェア ID**
: M-Logger 本体の個体番号 (8 桁の英数字)。Web サイトで出荷時試験成績を調べるときに使う。

**乾球温度**
: 一般に「気温」と呼ばれる空気の温度。

**グローブ温度**
: 黒い球 (グローブ球) の中心の温度。周囲の壁や窓などからの放射の影響を含む。

**平均放射温度 (MRT)**
: 周囲の面から受ける放射を、一様な温度の面に置き換えたときの温度。グローブ温度・乾球温度・風速から計算する。

**PMV / PPD**
: 温熱環境の快適性の指標。PMV は暑い・寒いの感覚を -3 (寒い) 〜 +3 (暑い) で表した予測値、PPD はその環境に不満を感じる人の割合の予測値 [%]。

**SET\***
: 標準新有効温度。温度・湿度・気流・放射・着衣量・代謝量の影響をまとめて、1 つの温度で表した指標 [°C]。

**WBGT**
: 暑さ指数。熱中症の危険度の目安に使う指標 [°C]。屋内用と屋外用の計算式がある。

**着衣量 (clo) / 代謝量 (met)**
: PMV などを計算するときの、服装の暖かさと、活動の激しさ。
