# M-Logger ユーザーマニュアル

室内温熱環境計測システム **M-Logger** の使い方をまとめたマニュアルです。本体の基本操作と、M-Logger を操作するソフトウェア (スマートフォンアプリ・MLServer・Python ツール) を説明します。

## このマニュアルの構成

| 章 | 内容 |
|---|---|
| [はじめに](start/system.md) | システムの構成、本体の基本操作、ファームウェアの版と対応機能・更新 |
| [スマートフォンアプリ](mobile/index.md) | 1 台の M-Logger をスマートフォンから設定・計測する |
| [PC (MLServer)](server/index.md) | Zigbee で複数台の計測値を PC に集める |
| [Python ツール](python/index.md) | USB で記録データの読み出し・消去、動作確認をする |
| [付録](appendix/troubleshooting.md) | トラブルシューティング、用語 |

## ファームウェアの版による違い

M-Logger のファームウェアの版によって、使える機能や画面が一部異なります。版の見分け方と、このマニュアルでの表し方は [ファームウェアの版と対応機能](start/firmware.md) を参照してください。
