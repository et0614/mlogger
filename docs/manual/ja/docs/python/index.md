# Python ツール

<span class="fw">v4 以降</span> この章のツールは USB で M-Logger と通信するため、v4 ファームウェアの M-Logger でのみ使えます。

PC に USB でつないだ M-Logger を、コマンドで操作するツールです。

| スクリプト | 用途 |
|---|---|
| [`check_device.py`](check_device.md) | 動作確認。接続、電池、プローブ、センサの現在値を表示する |
| [`load_data.py`](load_data.md) | 記録データをダウンロードして CSV ファイルに保存する |
| [`clear_data.py`](clear_data.md) | M-Logger に記録されたデータを消去する |

使う前に [準備](install.md) を済ませてください。
