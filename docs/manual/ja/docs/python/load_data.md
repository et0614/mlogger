# 記録データのダウンロード

M-Logger の内蔵メモリに記録したデータを、CSV ファイルに保存します。

```
python load_data.py
```

実行したフォルダに `mlogger_<ハードウェアID>_<日時>.csv` が作られます。M-Logger が計測中の場合はダウンロードできないので、計測を止めてから実行してください。

## オプション

| オプション | 内容 |
|---|---|
| `-o <ファイル名>` | 保存するファイル名を指定する |
| `--all` | 消去したデータも復旧して取り出す |

## CSV の形式

先頭に `#` で始まる行 (機器の情報、ダウンロードした日時など) があり、続いて列名の行、単位の行、その後に 1 記録 1 行でデータが並びます。

| 列 | 単位 | 内容 |
|---|---|---|
| `iso_time` | | 計測した日時 (PC の地域の時刻) |
| `ts` | s | 計測した日時 (UNIX 時刻) |
| `gen` | | データの世代番号 (消去のたびに増える) |
| `t_dry` | °C | 乾球温度 |
| `humidity` | % | 相対湿度 |
| `t_glb` | °C | グローブ温度 |
| `wind_speed` | m/s | 風速 |
| `voltage` | mV | 風速計の電圧 |
| `illuminance` | lx | 照度 |
| `co2` | ppm | CO2 濃度 |

空欄は、その時点でセンサを使っていなかったか、つながっていなかったことを表します。
