# 動作確認

M-Logger が正しくつながっていて、動いているかを確認します。

```
python check_device.py
```

## 表示される内容

1. **ポートの検索**: PC のシリアルポートを順に調べ、M-Logger が見つかったポートを表示します。見つからない場合は、ポートごとの状態 (使用中、応答なしなど) を表示します。
2. **機器の情報**: 名前、ハードウェア ID、ファームウェアの版、電池電圧、つながっているプローブ、記録データの件数。
3. **センサの現在値**: 短いテスト計測を行い、乾球温度、相対湿度、グローブ温度、CO2 濃度、照度、風速を表示します。

ハードウェア ID は、Web サイトで出荷時試験成績を調べるときにも使います。

テスト計測では、センサの準備 (ウォームアップ) に最大 90 秒ほどかかります。計測の設定を一時的に変更し、終わったら元に戻します。M-Logger が計測中の場合、テスト計測は行いません。

## オプション

| オプション | 内容 |
|---|---|
| `--no-live` | テスト計測を行わず、機器の情報だけを表示する |
