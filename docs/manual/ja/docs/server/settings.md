# 設定

## setting.ini

MLServer と同じフォルダにある `setting.ini` で設定します。1 行に 1 項目を `名前=値;` の形で書き、`//` 以降はコメントです。変更は MLServer の再起動後に反映されます。

| 項目 | 内容 | 初期値 |
|---|---|---|
| `bacnet` | BACnet 連携を使うか (`true` / `false`) | `true` |
| `bacip` | BACnet で使う PC の IP アドレス | `127.0.0.1` |
| `bacport` | BACnet で使うポート番号 | `47809` |
| `bacdevid` | BACnet の Device ID | `614` |
| `met` | 熱的快適性の計算に使う代謝量 [met] | `1.7` |
| `clo` | 熱的快適性の計算に使う着衣量 [clo] | `1.0` |
| `dbt` | 乾球温度を計測していない場合に使う値 [°C] | `25.0` |
| `rhd` | 相対湿度を計測していない場合に使う値 [%] | `50.0` |
| `vel` | 風速を計測していない場合に使う値 [m/s] | `1.0` |
| `mrt` | 放射温度を計測していない場合に使う値 [°C] | `25.0` |

BACnet の項目は [BACnet 連携](bacnet.md) を参照してください。

## mlnames.txt

MLServer は、M-Logger 本体に設定された名前 (スマートフォンアプリで設定) を自動で受け取って表示します。`mlnames.txt` は、現場で別の名前を付けたい場合に使います。ここに登録した名前は本体の名前より優先されます。

1 行に 1 台ずつ、M-Logger のアドレス (XBee アドレスの下位 8 桁) と名前を `:` で区切って書きます。`//` 以降はコメントです。

```
42114F7E:SIH-01
42114F57:SIH-02   // 2 階会議室
```

本体の名前を受け取るまでの間と、どちらの名前もない場合は、`MLogger_` にアドレス (16 桁) を付けた名前で表示されます。
